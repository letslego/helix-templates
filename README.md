# Helix Templates

Starter agents for the [Helix ecosystem](https://letslego.github.io/helix-ecosystem/).

## Templates

| Template | Description |
| --- | --- |
| [`blank-agent`](./blank-agent) | Minimal instructions + weather tool + console |
| [`travel-agent`](./travel-agent) | Full-stack demo: tools, sandbox, connect, subagents, schedules, evals |

## Use

```bash
npx @letslego/helix init my-agent
# or copy a template
cp -R travel-agent ../my-travel-agent
cd ../my-travel-agent && npm install && npx helix console
```
